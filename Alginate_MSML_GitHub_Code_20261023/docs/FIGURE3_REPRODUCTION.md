# Reproduction guide: Figure 3c, 3e, 3f

## Panel 3c — seven measured mixture compositions

`python figures/figure3c/plot_figure3c_nmf_errorbars.py --mode real --data-dir PATH --out-dir outputs/figure3c`

Uses the unchanged original V6.6/V7.0 source modules at the repository root and the **fixed** Gaussian parameter 1, ORIGINAL7 local group-area normalization, lambda 1. Fits a rank-two unsupervised NMF to all technical spectra of the DP3/NCE26 calibration compositions. The activation plot is descriptive, not a held-out accuracy evaluation.

Uses NMR-calibrated M% values 8, 23.4, 38.8, 46.5, 54.2, 69.6, 85; x ticks show 10...80 with limits sufficiently wide to include BOTH endpoints. The two component traces use seven means; error bars show mean ± 1 technical-scan SD. Output includes PNG (600 DPI), SVG, PDF, scan-level CSV, mixture-level summary CSV, caption, metadata. **No real mzML or measured Fig 3c NMF SVG has been provided in this repo.** The example SVG is *synthetic* and watermarked; never cite/submit as measured data.

## Panel 3e — group-level LOCO schematic

`python figures/figure3e_f/generate_clean_panel_e_f.py --out-dir outputs/figure3ef`

The seven column labels are **nominal MM-rich-stock percentages**, not true M% labels: 0%,20%,40%,50%,60%,80%,100%. All technical spectra from one mixture are held out as TEST each fold. A color legend remains, no plot title or panel letter. Panel is illustration only, based on the documented fold logic.

## Panel 3f — fixed-protocol MAE heatmap

Same command as 3e; uses `figures/figure3e_f/source_data/V70_FIG3F_LOCKED_15_CONDITIONS.csv`, generated by the V7.0 frozen-protocol analysis and copied verbatim here. Rows are NCE18/22/26 and columns DP3–DP7; 15 MAE values are **M percentage-point errors**, grouped LOCO n=7 composition-level predictions per cell. The color bar is calibrated from 0 to 10. Plot has no title or panel letter. **This is not the post-selected minimum over V6.6/V6.7 grids.**

## Testing and reproducibility

`python tests/test_figure3_scripts.py` validates the Figure 3c numerical grouping self-test, regenerates both SVG/PNG/PDF files for 3e/f in a temporary directory, and checks the 15 heatmap source rows. It does not establish scientific accuracy for the NMR assignments or the external samples.

## Source data and public-release caveats

- The supplied V7.0 results are included in `results/reported/v70/`. The repository package did not rerun the real spectral analysis.
- Figure 3c measured NMF source CSVs are not present; manuscript insertion should await an actual run and archived source data.
- The nominal Gaussian kernel setting may not equal a physical bandwidth in Da; verify before stating a measured smoothing width.
- The existing local sample preparations do not constitute independent biological replicates; technical spectra are nested within mixture composition.
- Bulk NMR data from external samples are DP-unresolved, not independent DP3/4 ground truth.


## Final Figure 3c manuscript label update (2026-10-23)

Panels now use neutral `NMF component (W1)` and `NMF component (W2)` titles, not M-/G-associated chemical labels. They depict scan-level mean ± SD at seven NMR-calibrated M% labels. W1/W2 refer to display order; the output metadata maps those labels to raw NMF columns.
